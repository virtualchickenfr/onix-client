PRIVACY

Onix Client contains no analytics, tracking or advertising. It only connects to Microsoft/Minecraft (sign-in and game files), Fabric, Modrinth, Adoptium (Java), GitHub (launcher updates, can be turned off in Settings), mc-heads.net (player heads) and - only if you set one - your Onix server. Details: PRIVACY.md in the source code (github.com/virtualchickenfr/onix-client).
