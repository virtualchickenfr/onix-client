Help

Questions & answers

The most important keys, common questions and what to do when something does not work.

The most important keys

Right ShiftOpen the Onix menu, in game and in the main menu
MOpen the world map (with the minimap on)
Ctrl + ClickCopy a chat message (with the chat open)
Right clickOn the world map: add a waypoint

Every module can get its own key to turn it on and off: in the Onix menu, under “Toggle Key” on the module. Move the HUD under “Edit HUD”.

Common questions

Does Onix cost anything?

No. Onix, the launcher and the Android app are free. You only need your own Minecraft account (Java Edition).

Can I play on servers like Hypixel with it?

Onix has no cheats, macros or aimbots, only displays, visuals and comfort. Still, always follow the rules of the server you play on.

Which Minecraft versions are supported?

Minecraft 1.21.1, 1.21.4, 1.21.6, 1.21.7, 1.21.8, 1.21.10 and 1.21.11, each with Fabric. You choose the version per profile in the launcher.

Do I get updates automatically?

Yes. The launcher and the phone app look for a new version on every start and install it.

Does Onix work with other mods?

Yes, you can add your own Fabric mods in the launcher, for example from Modrinth. With Essential, the Onix main menu also shows its friends, wardrobe and pictures.

Is Onix safe?

All of the source code is open on GitHub. Every download is built automatically from that code.

When something does not work

Minecraft does not start or crashes

The launcher reads the crash and names the mod that caused it. Turn that mod off in the profile and start again. If that does not help, Profile → Logs shows the full log.

My FPS is too low

Keep the performance pack on in the profile (Sodium, Lithium and more). Shaders cost a lot of FPS: they are off by default and should stay off on weaker PCs. In the Onix menu under Performance, “Performance Preset” sets the graphics to fast with one click.

How do I turn shaders on?

In the launcher: Profile → Shaders. Pick a look; the launcher installs Iris and the shader pack and turns it on. In game, the “Shaders” module turns them off and on again.

The world map is empty

The map only shows what the game has loaded and fills up as you move. In another dimension it starts fresh. Your Overworld map stays until you quit Minecraft.

The phone app does not start Minecraft

Minecraft needs a lot of memory on a phone. Close other apps and restart the Onix app. Older devices with little memory often cannot run newer Minecraft versions.

I found a bug

Report it on GitHub under Issues, ideally with a screenshot and your Minecraft version.
